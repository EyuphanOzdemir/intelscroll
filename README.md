# IntelScroll

A simple download page for the IntelScroll Android app.

Website: https://eyuphanozdemir.github.io/intelscroll/

Download: https://github.com/EyuphanOzdemir/intelscroll/releases/download/v1.2.0/IntelScroll-1.2.0.apk

IntelScroll turns your topics into short facts, concepts, outlines, diagrams, Q&A, and quizzes using your chosen AI provider. Gemini 3.1 Flash-Lite is the built-in starter. Use your own Gemini API key if you have one, or email ozdemireyuphan@gmail.com to request a starter key. Enter it using Set starter key on Models. No API credential is bundled in the APK; keys entered by users are stored securely on their devices. Availability depends on quotas and provider limits. Prompts are sent to your chosen provider, and usage charges may apply.

## Install on Android

1. Download the APK on a phone running Android 7.0 or later.
2. Open it and allow installation from your browser or file manager when Android prompts.
3. Install IntelScroll. On Models, tap Set starter key and enter your own Gemini key or one you requested by email. Add a topic and start learning, or configure a different provider with your own key.

The APK contains the app's JavaScript and runs without Metro or a computer. Internet access is needed to reach hosted AI providers.

## Website hosting

The single `index.html` page is published with GitHub Pages from the main branch. The APK is a GitHub release asset, not part of the website's Git history. This repository contains no API keys, app settings, signing files, or app source code.
