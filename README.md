# IntelScroll

A simple download page for the IntelScroll Android app.

Website: https://eyuphanozdemir.github.io/intelscroll/

Download: https://github.com/EyuphanOzdemir/intelscroll/releases/download/v1.2.0/IntelScroll-1.2.0.apk

IntelScroll turns your topics into short facts, concepts, outlines, diagrams, Q&A, and quizzes using your chosen AI provider. Start with the included Gemini 3.1 Flash-Lite model without setting up an API key, or bring your own provider and key. The starter uses shared free quota and can be slow or temporarily unavailable. Prompts are sent to your chosen provider, and usage charges may apply when using your own provider.

## Install on Android

1. Download the APK on a phone running Android 7.0 or later.
2. Open it and allow installation from your browser or file manager when Android prompts.
3. Install IntelScroll, add a topic, and use the included starter model or configure your own AI provider.

The APK contains the app's JavaScript and runs without Metro or a computer. Internet access is needed to reach hosted AI providers.

## Website hosting

The single `index.html` page is published with GitHub Pages from the main branch. The APK is a GitHub release asset, not part of the website's Git history. This repository contains no API keys, app settings, signing files, or app source code.
