# IntelScroll

A simple download page for the IntelScroll Android app.

Website: https://eyuphanozdemir.github.io/intelscroll/

Download: https://github.com/EyuphanOzdemir/intelscroll/releases/download/v1.3.0/IntelScroll-1.3.0.apk

IntelScroll turns your topics into short facts, concepts, outlines, diagrams, Q&A, and quizzes using your chosen AI provider. An invitation code unlocks Gemini 3.1 Flash-Lite during first-launch setup. Email ozdemireyuphan@gmail.com to request a code, or continue without one and add your own AI provider on Models. No API credential is bundled in the APK; provider keys are stored securely on the device. Availability depends on quotas and provider limits. Prompts are sent to your chosen provider, and usage charges may apply.

## Install on Android

1. Download the APK on a phone running Android 7.0 or later.
2. Open it and allow installation from your browser or file manager when Android prompts.
3. Install IntelScroll. On first launch, enter an invitation code to unlock the Gemini starter, or choose "I don't have one" and add your own AI provider on Models. Continuing without a code permanently dismisses invitation setup and hides the starter. Add a topic and start learning.

Existing users complete invitation setup once after updating; custom models and saved entries are retained.

The APK contains the app's JavaScript and runs without Metro or a computer. Internet access is needed to reach hosted AI providers.

## Website hosting

The single `index.html` page is published with GitHub Pages from the main branch. The APK is a GitHub release asset, not part of the website's Git history. This repository contains no API keys, app settings, signing files, or app source code.
